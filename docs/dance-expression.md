# 球のダンスと曲調表現（v2026.10.18.28）

Beat Thisから得た拍内位相・小節内位置・拍子の確信度を、そのまま動きの時間軸に使う。検出・時刻補償・補助追跡のアルゴリズムは変更しない。

| 情報 | 表現 |
|---|---|
| 3拍子 | 小節全体を円弧で巡る揺れ、1拍目の重み、次の小節へ続く旋回 |
| 4拍子 | 左右を交互に踏むステップ、2・4拍目の弾み、小節全体の緩やかな上下動 |
| 小節頭 | 広がり、発光、色へのアクセント。粒子は小さく伸縮 |
| 拍子の確信度 | 未確定では自由な拍の揺れ。弱い拍子情報は段階的に混ぜ、断定した振付にしない |
| 活動感 | 動きの振幅、流れの速さ、追従の鋭さを緩やかに変える |
| 温かみ・緊張・音色 | 従来の連続的な色相分布と彩度、背景色に反映。全色相・色の例外・色の休息を維持 |
| 活動的 | 中心からの放出を増やし、退場は外への発散を増やす |
| 穏やか | 中心への引力を受ける個体と力を増やし、退場は中心収束を増やす |

活動感の算出は、テンポ×確信度45%、音量に対する相対的な立ち上がり35%、音量20%で合成する。入力音量が自動で増幅されても、定常音まで一律に活動的としない。活動感は約4秒、動きへの反映はさらに約1.2秒で馴染ませる。温かみ・緊張の推定は既存の連続推定を使用し、楽曲ジャンルや感情を分類したものではない。

中心発生の基本割合は活動感に応じて30〜75%、中心収束の基本割合は78〜36%へ変わる。反対の動きは必ず残す。発生は中心一斉・中心から順次・画面外の一方向・画面外の複数方向、退場は収束・発散とそれぞれの渦付きの4種類で、全組み合わせを選択可能にする。各登場の最初に選択し、曲調変化で生きている粒子の位置や運動をリセットしない。画面が空白になった場合の回復は従来どおり中心から行う。

群れごとに向き・振幅・長い呼吸周期を変え、個体ごとの参加量も変える。通常の移動は従来の慣性・速度・加速度制限を維持する。これとは別に描画位置へ拍同期の揺れを重ね、通常移動の多段の慣性で拍の振幅が消えないようにする。参加量は少なくとも1.2秒・3拍かけて育ち、追跡停止時は約0.35秒で弱まる。描画オフセットは毎秒、通常速度上限の55%以内で変化させ、位相補正でも位置を飛ばさない。これは通常移動に加算する描画運動の上限であり、合成後の画面上速度は通常移動だけの上限を超える場合がある。

中央からの放射は拍時計に同期する独立した短命の粒で表現する。小節頭は24粒、その他の拍は7粒。曲調が活動的なほど明るく遠くへ広がる。最大4拍分・各1.35秒の残光に限定し、恒常的な群れの個体数は増やさない。開始時刻を描画時に置かず、遅延補償済みの拍内位相から経過秒を逆算する。拍子未確定では弱い放射を使い、確信度が失われた場合は停止する。

検証：スマートフォン相当幅で拍同期の表示位置が縦横とも10px以上往復すること、数拍かけて参加量が増すこと、オフセット変化速度の上限、追跡停止での減衰、強拍と弱拍の粒数・明るさの差、拍からの経過秒と放射距離の比例を自動テストで確認する。3拍子・4拍子の実ブラウザ描画とPWAの保存・オフライン推論・入力再同期も確認する。

## 球の膨張・収縮（v2026.10.18.28）

画面中心を固定し、三角形・ひし形に中心を動かす機能を廃止する。球自体の半径と光の大きさだけを拍同期で変え、画面全体の平行移動や拡大縮小は行わない。通常の球の移動・放射は維持する。

約2/3の球が同じ周期で膨張・収縮する。3拍子または4拍子が2秒以上安定し、拍子確信度80%以上なら、参加率を約90%まで約1.6秒かけて増やす。各個体は固有の参加順位を持ち、境界の個体は徐々に参加する。残りは通常の表現を続ける。半径の振幅は曲調に応じて±32〜44%。実サイズを書き換えないので、分裂・合体時の面積や運動量の計算に影響しない。

1周期（収縮→膨張→収縮）は、未確定・4拍子なら通常2拍、速い曲は4拍。3拍子なら遅い曲は1拍、通常3拍。テンポ境界は150／90 BPM、往復の余裕は±8 BPM。周期変更は周期境界で適用し、拍子変更でも位相をリセットしない。開始時は約1.2秒で振幅が育ち、拍追跡停止時は約0.65秒で元の大きさに戻る。BPM未確定時は同期した膨張・収縮を行わない。

検証：参加率、テンポ別周期、位相補正・拍子変更の連続性、追跡停止での減衰、中心の固定、描画時の球の位置が変わらず半径だけが大きく変化すること。
