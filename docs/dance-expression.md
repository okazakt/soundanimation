# 球のリズム表現（v2026.10.18.32）

中心固定。拍同期の平行移動・揺れ・旋回・群れ半径変化・色アクセントは廃止。球の約3倍の膨張・収縮に加え、固定中心からの放射と慣性のある加減速を残す。速度係数だけを最大30%増やす信号を、加速約0.35秒・減速約0.7秒でならし、既存の速度・加速度上限を維持する。放射は小節頭24粒、その他7粒、最大4拍分・1.35秒の残光に限定する。追跡停止時は放射を停止し、加速を減衰する。出入り、分裂・合体、色の休息にも拍境界を使わない。通常の漂い、曲調による緩やかな動き・色の変化は維持する。移動上限はテンポで変えない。

約2/3の球が同じ周期で膨張・収縮する。3拍子または4拍子が2秒以上安定し、拍子確信度80%以上なら、参加率を約90%まで約1.6秒かけて増やす。各個体の参加順位は固定し、境界の個体は徐々に参加する。残りは通常の表現を続ける。

半径・直径の最大は通常の約2.95〜3.05倍、最小は0.65倍。実サイズを書き換えないので、分裂・合体時の面積や運動量の計算に影響しない。

| 周期内の区間 | 動作 |
|---|---|
| 0〜16% | 0.65倍から約3倍へ膨張 |
| 16〜58% | 約3倍から0.65倍へ収縮 |
| 58〜100% | 小さい状態で待機 |

端の速度・加速度がゼロの補間を使用。1周期は未確定・4拍子なら通常2拍、速い曲は4拍。3拍子なら遅い曲は1拍、通常3拍。テンポ境界150／90 BPM、往復の余裕±8 BPM。周期変更は周期境界で適用し、拍子変更でも位相をリセットしない。開始時は約1.2秒で振幅が育ち、拍追跡停止時は約0.65秒で元の大きさに戻る。BPM未確定時は同期した膨張・収縮を行わない。

検証：拍から位置・旋回・群れ半径に直接変化を加えないこと、加減速の連続性、中心固定の放射と追跡停止、最大3倍、参加率、テンポ別周期、拍子変更の連続性、追跡停止での減衰、中心固定、サイズ変化が球の位置を変えないこと。

## 描画ゲートと位相同期の修正

マイクでBeat Thisが動作する場合、拍追跡が始まるまでは球の発生を止める。信頼度35%以上、55〜200 BPM、モデルまたは整合するアタックの支持が6秒（低速では8拍）以内、継続無音が0.8秒（低速では1.5拍）未満なら表示する。入力の絶対音量はゲートに使わない。確かな拍がある場合、周波数表示が弱くても最低限の発生量を確保する。支持が途切れると新規発生を止め、既存の群れは通常の退場で消える。推論は表示停止中も続ける。デモ・AI未対応時の既存の音反応表示は維持する。

サイズの位相は描画側の周期積算から、補正後の拍時計の絶対拍数・拍内位相への追従に変更する。負方向の補正も取り込み、誤差を約0.12秒でならして修正する。最大膨張を選択された拍に合わせるため、膨張の16%区間は拍の直前へ移す。拍の後42%で収縮、続く42%は待機、最後の16%で次の選択拍へ膨張する。通常120 BPM・2拍周期では、拍の瞬間が最大、420msで収縮、420ms待機、次の160msで次の最大へ至る。3倍と参加率・周期選択は維持する。

3分間の補正付き時計で位相誤差が蓄積しないこと、増幅ノイズのみでは非表示、弱い入力でも支持された拍があれば表示、支持停止で消えることを検証する。
