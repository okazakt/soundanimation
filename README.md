# Starlight Bell

マイク入力を画面全域の光で可視化するビルド不要のPWAです。描画領域の全画素（高DPIの実画素を含む）に、固定のランダムな周波数帯と明るさの倍率を割り当てます。星の個数や配置リストはなく、端を含めた全画素が発光候補です。

音声は40Hz〜14kHz（上限はナイキスト周波数）の512帯域を使用します。FFTの分解能は有限なので、複数の画素が同じ帯域を共有します。音が弱まったときは時定数1.8秒の指数補間で、約5秒かけて輝きが約6%まで滑らかに減衰します。無音時に常時表示する星はありません。

## 利用

リポジトリのルートで次を実行し、`http://localhost:8000/` を開きます。

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

マイクとService WorkerにはHTTPS（開発時はlocalhost）が必要です。

- 開始：マイク許可を要求し、描画と画面のスリープ防止を開始。
- 終了：描画を停止し、マイクとWake Lockを解放。
- マイクが使えない場合：通知後、再現可能なシミュレーションで動作。
- 録音、保存、音声送信、スピーカーへの出力は行いません。

localStorage・IndexedDBは使用しません。Service Workerとマニフェストの範囲はこのディレクトリ内のみです。キャッシュ名は `starlight-bell-soundanimation-` から始まり、それ以外のキャッシュは読み書き・削除しません。

同じオリジンにある別アプリが全キャッシュを削除した場合、このアプリのオフライン用キャッシュも消えます。再びオンラインでページを開くと、必要なファイルが再キャッシュされます。

## 検証

```sh
node tests/app.test.cjs
```

実機では、マイク許可・拒否、準備中の終了、再開始、画面回転、バックグラウンド復帰、ホーム画面への追加、オンラインでの読込後のオフライン起動を確認してください。Wake Lockや全画面表示はブラウザの対応状況によって異なります。

60fps時の仕様の係数を、経過時間で補正して使用します。明順応は待機を挟まず直後から始まり、約0.5秒で落ち着きます。起動時のシードは固定ですが、実際の輝きはマイク入力に依存します。

画面右上には、実行中のJavaScriptのバージョンを表示します。現在は `v2026.10.17.1` です。更新時は `app.js` のVERSION、HTMLのJS/CSS URL、Service Workerのキャッシュ名とアセットURLを同じバージョンに更新します。
